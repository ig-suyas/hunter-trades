## 2. Repair rules and rows touched

Rules (implemented in `crates/cs-data/src/clean.rs`, applied at load time, in this order):

- **R1 timestamp unit**: a timestamp >= 1e14 is in microseconds (Binance spot archive files from 2025-01-01 onward) and is divided by 1000 (open_time and close_time).
- **R2 misaligned rows dropped**: after R1, a candle whose open time is not a whole UTC minute is dropped.
- **R3 out-of-order rows sorted**: stable sort by time; the count is rows that were earlier than the row before them.
- **R4 exact duplicates dropped**: same time and identical values.
- **R5 conflicting duplicates**: same time, different values; the first row in file order is kept.
